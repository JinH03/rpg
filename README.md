# python Text Rpg
파이썬을 이용해 만든 텍스트 rpg 게임

## 기능
- 캐릭터 이름 입력
- 쉬움, 보통, 어려움 난이도 선택
- 슬라임, 고블린, 드래곤과 전투
- 공격 데미지 랜덤 적용
- 공격 또는 도망 선택
- 몬스터 처치 시 체력 회복
- 몬스터별 경험치와 골드 보상
- 경험치 획득 및 레벨업
- 최대 체력을 넘지 않도록 체력 제한
- 전투 종료 후 게임 저장 및 종료
- 캐릭터 정보를 JSON 파일로 저장
- 상점에서 체력 회복 및 공격력 강화 물약 구매
- 전투 중 인벤토리의 물약 사용
- 몬스터 카운터 공격 추가


## 사용기술 
python
random
json

## 앞으로 추가할 기능
1. 몬스터별 경험치와 보상 차이
2. 캐릭터 직업 선택
3. 아이템과 인벤토리
4. 함수에 매개변수를 전달하도록 코드 개선
