# 🎮 Python Text RPG v1.0

Python을 활용하여 제작한 콘솔 기반 텍스트 RPG 프로젝트입니다.

Python의 기본 문법과 함수, 자료구조, 파일 입출력, JSON, Git/GitHub 등을 직접 활용하여 게임의 핵심 기능을 구현했습니다.

## 📌 프로젝트 소개

플레이어가 캐릭터를 생성하고 몬스터와 전투하며 경험치와 골드를 획득하는 간단한 텍스트 RPG입니다.

전투를 통해 캐릭터를 성장시키고, 골드로 포션을 구매하여 전투에 활용할 수 있습니다.

게임 진행 상황은 JSON 파일을 이용하여 저장하고 불러올 수 있습니다.

## 🛠️ 사용 기술

- Python
- JSON

## 🎮 주요 기능

### 👤 캐릭터

- 캐릭터 이름 설정
- 레벨 시스템
- HP / 최대 HP
- 공격력
- 경험치
- 골드

### ⚔️ 전투

- 난이도에 따른 몬스터 선택
- 일반 공격
- 몬스터 반격
- 카운터 공격
- 도망
- 몬스터 처치
- 경험치 및 골드 획득
- 레벨업

### 🏪 상점 및 인벤토리

- 체력 회복 물약 구매
- 공격력 강화 물약 구매
- 인벤토리 관리
- 체력 회복 물약 사용
- 공격력 강화 물약 사용

### 💾 저장 / 불러오기

JSON을 이용하여 게임 진행 상황을 저장하고 불러올 수 있습니다.

저장되는 정보:

- 캐릭터 이름
- 레벨
- 경험치
- HP
- 최대 HP
- 공격력
- 골드
- 인벤토리

## 🚀 실행 방법

Python이 설치된 환경에서 프로젝트를 실행합니다.

```bash
python rpg.py
```
